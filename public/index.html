WHAT ARE WE TESTING?

A choice, then a move.

Jev is a decision model from TypeSafe. It takes text and picks from a set of options. It does not see the board image.

  1. The app sends the board state and every legal move.
  2. Jev picks one move and returns a probability for each option.
  3. The app checks that choice, then moves the piece.

No chess engine scores, search results, or mate markers go into the options. The chess rules library handles legality. The scores in the panel show Jev’s choice distribution, not chess strength or win odds.

Made for a quick experiment

Try “Find the finish” for a one-move test. Switch to “Jev vs Jev” for a live match. Auto-play pauses after 80 turns. You can export every recorded move and API result.

Chess is a hard test of planning. Connect Four is easier to explain in a short video. Neither is a measured benchmark of this model.
